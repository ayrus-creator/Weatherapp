# Weather App

A simple weather application built using HTML, CSS, and JavaScript.

The application allows users to search for a city and view its current temperature and weather condition using live weather data.

## Features

- Search for weather using a city name
- Display the current temperature
- Display the current weather condition
- Display the searched city name
- Fetch live data from an external weather service
- Glassmorphism-inspired weather card
- Gradient background
- Button and card hover effects
- Clean and simple user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Fetch API
- wttr.in Weather API
